# ✈ FD Performance — Flight Dispatcher Handbook

**Progressive Web App (PWA)** สำหรับ Flight Dispatcher และ Pilot  
อ่านได้ทั้ง **มือถือ · Tablet · คอมพิวเตอร์** และ **ติดตั้งเป็นแอพ** บน Home Screen ได้

## 🌐 เปิดอ่านออนไลน์

**→ [เปิดแอพ](https://YOUR-USERNAME.github.io/fd-performance-app/)**

## 📱 วิธีติดตั้งเป็นแอพ

### iPhone / iPad (Safari)
1. เปิดลิงก์ใน **Safari**
2. กดปุ่ม **Share** (□↑) ด้านล่าง
3. เลือก **"Add to Home Screen"**
4. ตั้งชื่อ `FD Performance` → กด **Add**

### Android (Chrome)
1. เปิดลิงก์ใน **Chrome**
2. กด **ปุ่มเมนู** (⋮) มุมบนขวา
3. เลือก **"Add to Home Screen"**  
   หรือรอ Banner **"ติดตั้ง FD Performance"** ปรากฏขึ้นเอง

### หลังติดตั้ง
- แอพอยู่บน Home Screen มีไอคอน ✈
- เปิดได้แบบ **Fullscreen** ไม่มี Browser bar
- อ่านได้ **Offline** แม้ไม่มีสัญญาณ

## ⚡ Features

- 📖 **11 บท** เนื้อหาครบ ICAO Annex 6 / FAR 121
- 🔍 **Full-Text Search** — ค้นหาคำในทุกบท
